# 🧮 Scientific Calculator

A responsive **Scientific Calculator** built with **HTML, CSS, and JavaScript**. The application performs basic arithmetic operations along with additional scientific functions such as logarithm and square.

This project was created to practice JavaScript fundamentals, DOM manipulation, event handling, and mathematical operations while building an interactive web application.

---

## ✨ Features
- Perform basic arithmetic operations:
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
- Calculate squares.
- Calculate logarithmic values.
- Clear and delete input functionality.
- Responsive and user-friendly interface.
- Instant calculation results.
- Handles invalid inputs gracefully (shows "Error" for cases like log of a negative number).
